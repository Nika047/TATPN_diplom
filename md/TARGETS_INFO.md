# База целей: объекты инфраструктуры СПб и Ленинградской области

## Назначение
Реальные координаты объектов критической инфраструктуры для использования в системе прогнозирования целей БПЛА. Координаты взяты из открытых источников (Wikipedia, Wikimapia, OpenStreetMap, официальные сайты).

## Зона полётов (данные обучения)
Логи полётов дронов записаны в районе **Гатчина / Коммунар** (~59.045 N, 29.093 E), примерно 45 км к югу от Санкт-Петербурга.

## Примечания
- Расстояния от зоны полётов указаны приблизительно (по прямой)
- Координаты соответствуют центру объекта (для крупных — центр территории)
- В реальной системе ПВО база целей будет значительно больше и включать засекреченные объекты
- Для дипломной работы 15 целей — достаточный объём для демонстрации работоспособности модели
