## Анализ текущего датасета

### Масштаб полётов (после фильтрации GPS-аномалий)
- **126 файлов** с валидным GPS
- **16 файлов** с битым/аномальным GPS (мусорные координаты, скачки на тысячи км)
- Медиана: **322 точки**, **10.7 мин** полёта, **1762 м** макс. удаление от старта
- 39 полётов с удалением > 5 км, лучшие до **15 км**
- Высота: обычно до 500 м, отдельные до 1000 м

### Проблемы для нашей задачи

**1. Траектории слишком короткие и локальные**
Типичный полёт — кружение над площадкой в радиусе 1-10 км. Боевые БПЛА летят на десятки-сотни км к конкретной цели. Наши данные — это учебные полёты, а не маршруты «старт → цель».

**2. Нет целенаправленного движения**
Учебные полёты — это кружение, пробные манёвры, возврат к оператору. Боевой дрон летит более-менее направленно к цели с возможными манёврами уклонения.

**3. GPS-артефакты**
~13% файлов содержат аномалии: скачки координат, нереальные высоты (-33293 м, +30512 м).

**4. Модели БПЛА — не релевантны для боевой задачи**
Chimera7, Dolphin, F450 и т.д. — это конкретные учебные аппараты. В боевом сценарии модель дрона неизвестна. Но в дипломе это нормально указать: «Обучение проводилось на данных реальных полётов следующих моделей БПЛА: ... Данные использовались для извлечения кинематических характеристик движения, типичных для БПЛА различных типов (самолёт, коптер, VTOL)».

## Слой 1: Реальные данные (используем как есть)

### Предобработка
1. **Фильтрация GPS-аномалий**: удалить точки со скачками > 500м за шаг
2. **Перевод в метры** (ENU — East-North-Up от точки старта)
3. **Ресемплирование**: интерполяция на фиксированный шаг dt=1с (сейчас ~2с между точками)
4. **Вычисление кинематики**: скорости, ускорения, курс, кривизна

### Роль в обучении
Эти данные дают модели **реалистичную кинематику**: как реально выглядит GPS-шум, как ускоряется/поворачивает реальный дрон, какие скорости типичны. Модель учится на реальных «паттернах движения».

### В дипломе
«Для обучения использованы реальные данные телеметрии 126 полётов БПЛА различных типов (самолёт, коптер, VTOL), предоставленные компанией "Ленинец". Данные содержат GPS-координаты с частотой ~0.5 Гц.»

## Слой 2: Расширенные реальные данные

### Метод A: Scale & Translate (масштабирование)
```
Берём реальную траекторию (кружение в радиусе 5 км)
→ Масштабируем координаты в 10-50 раз
→ Получаем «полёт» в радиусе 50-250 км
→ Сдвигаем в район какой-либо цели на карте
```
Кинематика остаётся реалистичной, но масштаб боевой.

### Метод B: Stitch (сшивка)
```
Берём 3-5 реальных траекторий
→ Выбираем «прямолинейные» участки
→ Соединяем сплайном в один длинный маршрут
→ Направляем от точки старта к точке цели
```
Получаем длинные маршруты с реалистичными манёврами.

### Метод C: Warp to Target (деформация к цели)
```
Берём реальную траекторию
→ Вычисляем «генеральный курс» (от первой к последней точке)
→ Поворачиваем и растягиваем, чтобы конец совпал с целью
→ Добавляем участок «подхода к цели» (последние 5 км — более прямолинейно)
```

### Кол-во: ~500 траекторий

## Слой 3: Синтетические боевые сценарии (ОСНОВНОЙ ОБЪЁМ)

### Идея
Генерируем траектории, которые моделируют реальные паттерны боевых вылетов БПЛА.

### Типы траекторий

**Тип A: Прямой маршрут (60% траекторий)**
```
Старт → (прямая линия с шумом) → Цель
- Случайная начальная точка на расстоянии 30-300 км от цели
- Генеральный курс на цель ± случайное отклонение
- Добавление GPS-шума (σ = 5-20 м)
- Добавление ветрового сноса (синусоидальное отклонение)
- Скорость: 80-200 км/ч (типична для БПЛА)
- Высота: 50-2000 м с плавными изменениями
```

**Тип B: Маршрут с уклонением (20%)**
```
Старт → Промежуточная точка 1 → Промежуточная точка 2 → Цель
- 1-3 промежуточных waypoint (обход ПВО/рельефа)
- Между waypoints — сглаженные сплайны
- Финальный участок (последние 10-20 км) — более прямой
```

**Тип C: Маршрут с разведкой (10%)**
```
Старт → Зона барражирования → Цель
- Участок кружения над промежуточной точкой
- Затем прямой заход на цель
- Моделирует дроны-барражирующие боеприпасы (Lancet, Shahed)
```

**Тип D: Ложный маршрут (10%)**
```
Старт → Направление к цели А → Смена курса → Цель Б
- Начало маршрута направлено на одну цель
- В середине — смена курса на другую
- Усложняет задачу для модели (проверка, что модель не 
  «привязывается» к начальному курсу)
```

### Физическая модель движения

```python
def generate_trajectory(start, target, speed_range, alt_range, noise_sigma):
    """
    Генерирует реалистичную траекторию БПЛА от start к target.
    """
    distance = haversine(start, target)
    speed = random.uniform(*speed_range)
    duration = distance / speed  # секунды
    n_points = int(duration / dt)
    
    # Базовый прямой маршрут
    t = np.linspace(0, 1, n_points)
    base_x = start[0] + (target[0] - start[0]) * t
    base_y = start[1] + (target[1] - start[1]) * t
    
    # Добавление реалистичных отклонений:
    # 1. Ветровой снос (низкочастотный)
    wind_drift = amplitude * np.sin(2*pi*t * n_waves) 
    
    # 2. Манёвры уклонения (средняя частота)
    maneuvers = random_spline_deviation()
    
    # 3. GPS-шум (высокая частота)
    gps_noise = np.random.normal(0, noise_sigma, n_points)
    
    # 4. Высота: плавный профиль с набором и снижением
    altitude = generate_altitude_profile(alt_range, n_points)
    
    # 5. Скорость: не постоянная, а с вариациями ±15%
    speed_profile = speed * (1 + 0.15 * np.sin(random_phase * t))
    
    trajectory = base + wind_drift + maneuvers + gps_noise
    return trajectory  # (N, 4) = x, y, z, t
```

## Формирование обучающей выборки

### Одна обучающая пара:
```
Вход:  первые X% траектории (наблюдаемый участок)
Метка: {
    target_id: ID цели (int)
    future_points: оставшиеся (100-X)% точек (для Trajectory Head)
    eta: время до конечной точки (float, секунды)
}
```

### Варьирование X% (процент наблюдения):
```
X = random(20%, 80%)
- При X=20%: видим только начало → сложная задача
- При X=80%: видим почти всё → лёгкая задача
- Модель учится предсказывать цель на разных этапах полёта
```

Это ключевой момент: **чем раньше модель может предсказать цель — тем ценнее она для ПВО**.
