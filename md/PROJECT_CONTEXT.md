# Контекст проекта: Система прогнозирования положения воздушного объекта

## Тема дипломной работы
Система прогнозирования положения воздушного объекта при помощи алгоритмов экстраполяции на основе нейронной сети

├── CNN.py                       # Простая CNN-модель (базовая, не используется в main)
├── CNN_transform_network.py     # Основная модель: CNN + Transformer (гибрид)
├── dataloader.py                # Загрузка и подготовка данных

├── generate_syntetic_data.py    # Генерация синтетических траекторий (сплайны)

### Формат данных CSV
Логи телеметрии с пультов управления (формат OpenTX). Ключевые поля:
- **GPS**: `"широта долгота"` (строка, пробел-разделитель) → X, Y
- **Alt(m)**: Высота в метрах → Z  
- **Time**: Временная метка `HH:MM:SS.fff`
- **Date**: Дата полёта
- Дополнительно: VSpd, GSpd, Hdg, Ptch, Roll, Yaw, Curr, Bat% и др.

### Предобработка данных
- GPS-координаты парсятся в X (широта), Y (долгота), Z (высота)
- Временные метки переводятся в секунды от начала полёта → dt
- Формат входа модели: `(X, Y, Z, dt)` — 4 признака
- Аугментация: аффинные преобразования, интерполяция с шумом, комбинирование траекторий

## Текущая архитектура (ConvTransformerTrajectory)

### Вход
- `(B, T, 4)` — батч × длина последовательности × 4 признака (x, y, z, dt)

### Блок 1: 1D-CNN (локальные паттерны)
- Conv1d(4→32, k=5) → BN → ReLU → MaxPool(2)
- Conv1d(32→64, k=3) → BN → ReLU → MaxPool(2)
- Conv1d(64→128, k=3) → BN → ReLU → MaxPool(2)
- Выход: `(B, T/8, 128)`

### Блок 2: Transformer Encoder (глобальные зависимости)
- Линейная проекция: 128 → 256
- Синусоидальное позиционное кодирование
- 4 слоя TransformerEncoder, 8 голов, FFN=512, GELU
- Global Mean Pooling → `(B, 256)`

### Блок 3: FC Head (прогноз)
- Linear(256→256) → ReLU → Dropout
- Linear(256→128) → ReLU → Dropout
- Linear(128→60) → reshape → `(B, 20, 3)`

### Выход
- `(B, 20, 3)` — предсказание 20 точек × 3 координаты (x, y, z)

### Параметры обучения
- Оптимизатор: AdamW (lr=1e-3, weight_decay=1e-4)
- Scheduler: ReduceLROnPlateau (по ADE)
- Loss: MSELoss
- Grad clipping: 1.0
- Batch size: 32, Epochs: 20
- seq_len=100, pred_horizon=20

### Дополнительная функциональность
- Зонная классификация: пространство делится на сетку 3×3×3 (27 зон)
- Для каждой предсказанной точки вычисляется RBF-вероятность принадлежности к зоне
- Метрики: Step Top-1 Accuracy, Final-step Accuracy, Brier Score
