## Формат CSV
Формат OpenTX телеметрии. Столбцы (60+):

### Используемые в проекте
| Столбец  | Описание                     | Использование          |
|----------|------------------------------|------------------------|
| GPS      | "широта долгота" (строка)    | → X, Y координаты      |
| Alt(m)   | Высота в метрах             | → Z координата          |
| Time     | HH:MM:SS.fff                | → dt (секунды от старта)|
| Date     | Дата полёта                 | Не используется         |

### Потенциально полезные (не используются)
| Столбец   | Описание                     | Потенциал                |
|-----------|------------------------------|--------------------------|
| GSpd(kmh) | Скорость по земле            | Вектор скорости          |
| VSpd(m/s) | Вертикальная скорость        | Динамика набора высоты   |
| Hdg(°)    | Курс (heading)              | Направление движения     |
| Ptch(rad) | Тангаж                       | Ориентация БПЛА          |
| Roll(rad) | Крен                         | Ориентация БПЛА          |
| Yaw(rad)  | Рыскание                     | Ориентация БПЛА          |
| FM        | Flight Mode (ANGL, AH, STAB) | Тип полётного режима     |
| Curr(A)   | Ток                          | Энергетика               |
| Bat%(%)   | Заряд батареи               | Ограничение полёта       |
| Sats      | Количество спутников GPS     | Качество GPS данных      |

## Типы БПЛА и их динамика

### Самолёты (Dolphin, Z84, Mini Talon, GoDiscover, Sim)
- Не могут зависать на месте
- Плавные траектории, большие радиусы поворотов
- Постоянная поступательная скорость
- Ограниченные углы тангажа и крена

### Коптеры (Chimera7, F450)
- Могут зависать, резко менять направление
- Более "рваные" траектории
- Высокая маневренность
- Вертикальный взлёт/посадка

### VTOL (T1 VTOL)
- Комбинированная динамика: взлёт/посадка как коптер, полёт как самолёт
- Переходные режимы между типами полёта

## Проблемы текущей предобработки

1. **GPS в формате строки**: Парсится через split, могут быть ошибки
2. **Координаты в градусах**: Широта/долгота без перевода в метры — масштаб ~1e-4 на метр
3. **Переменная частота записи**: ~2 сек между точками (не фиксированный dt)
4. **Нет фильтрации выбросов**: GPS-артефакты при потере спутников
5. **Нулевой padding**: Траектории разной длины дополняются нулями

## Рекомендации по улучшению

1. Перевести GPS в локальную метрическую систему (ENU или UTM)
2. Ресемплирование на фиксированный шаг по времени
3. Фильтрация GPS-выбросов (по скорости и Sats)
4. Добавить кинематические признаки (скорость, ускорение, курс)
5. Добавить тип БПЛА как категориальный признак (embedding)
6. Нормализация данных перед подачей в сеть
