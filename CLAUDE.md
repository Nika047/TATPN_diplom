# Claude Code

- `AGENTS.md` и `md/` - общая память проекта для всех агентов (Claude Code,
  Codex и других). Правила и решения писать только туда.
- Не хранить проектные решения в auto memory Claude: другие агенты её не увидят.
- Тематические документы выбирать по таблице маршрутизации в конце `AGENTS.md`,
  не загружая их все без необходимости.
- Общие правила пользователя (язык, тире, стиль, документация) лежат в
  `~/.claude/CLAUDE.md` и действуют поверх этого файла.
